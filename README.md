# 极速外卖 🍕

纯前端外卖点餐网站，单文件 SPA，无需后端服务器，数据存储在浏览器 localStorage。

## 功能

- 🏠 **餐厅浏览** — 8 家餐厅，搜索和分类筛选
- 📋 **菜单点餐** — 多分类菜单，加减购物车
- 🛒 **购物车** — 修改数量、自动计算配送费
- 💳 **下单结算** — 地址管理、支付方式选择
- 📦 **订单跟踪** — 从接单到送达，5 步进度条
- 👤 **用户系统** — 注册/登录，订单历史
- 🏪 **商家后台** — 接单、制作、配送、完成

## 使用方式

直接用浏览器打开 `index.html` 即可。

## 技术

- 纯 HTML/CSS/JS，零依赖
- Hash 路由实现 SPA
- localStorage 数据持久化
- 移动端优先设计（仿美团/饿了么风格）

## 部署

支持 GitHub Pages：仓库 → Settings → Pages → 选择分支 → Save。
